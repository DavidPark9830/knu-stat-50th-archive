학과 연혁, 교육·연구 성과, 학생 수상, 동문, 장학, 사업, 국제교류와 기념행사 자료를 정리한 아카이브입니다.

- 사진 **1,027장**: 큰 챕터별 분류와 날짜순 정리, 태그·출처·원본 해상도 표시
- 조사 기록 **497건**: 연혁·행사·학회·공모전 등 15개 분류
- 졸업앨범 PDF **30건**: 동창회 홈페이지의 연도 분류를 우선
- 사업·학회 원문 문서와 교수·연구실 공개 자료

[자료 아카이브 보기](https://davidpark9830.github.io/knu-stat-50th-archive/)

## 파일 구성

| 폴더·파일 | 내용 |
|---|---|
| `index.html` | 사진을 바로 볼 수 있는 자료보관함 |
| `사진원본/` | 날짜·자료 제목·사진 순번으로 이름을 정리한 보관본 |
| `미리보기/` | 웹문서 표시용 경량 이미지. 별개의 사진이 아닌 원본의 파생 파일 |
| `문서/` | 졸업앨범, 사업 문서, 학회 공식 자료 |
| `자료목록/` | 사진 메타데이터, 조사 기록, 큰 챕터 제목 |
| `웹문서/` | 문서 스타일과 검색·확대 기능 |
| `도구/` | 자료목록으로 웹문서를 다시 만드는 도구 |

기념영상 대본, 더빙 비교, 계정 정보, 작업용 원본 코드는 공개하지 않습니다. 대용량 행사 영상은 이 저장소에 포함하지 않으며, 해당 기록에는 출처와 미리보기를 표시했습니다.

## 파일명 규칙

자료 파일 이름에는 한글·영문·숫자·밑줄·하이픈만 사용하고, 점은 확장자 앞에만 둡니다. 사진 제목과 설명에는 원래 표기를 유지합니다.

## 사진 선택 기준

같은 사진은 대표본 하나로 정리합니다. 해상도와 함께 노출·왜곡·스캔 상태를 고려하며, 졸업앨범과 동창회 보관본이 겹치면 상태가 더 나은 보관본을 우선합니다. 표정이나 자세가 다른 연속 촬영 사진은 별개 기록으로 보존합니다. 낮은 해상도의 자료는 원본 확보 필요 상태를 유지했습니다.

사진 날짜가 불명확한 경우 연도·월 또는 미상으로 표시합니다. 게시일, 행사일, 원본 파일명 연도가 다른 경우 자료 설명을 함께 확인해 주세요.

## 로컬 열기와 문서 갱신

`index.html`을 브라우저에서 열면 됩니다. 로컬에서는 원본 파일을 직접 열고, GitHub Pages에서는 저장소의 원본 파일로 연결합니다. 페이지에는 경량 미리보기를 배포하고 고해상도 보관본은 저장소에 보존합니다.

메타데이터 변경 후 다음 명령으로 문서를 갱신할 수 있습니다.

```sh
python3 도구/웹문서_다시만들기.py
```

## 출처와 이용

각 사진과 기록에 원문 출처를 표시했습니다. 이 아카이브는 경북대학교의 공식 홈페이지가 아닙니다. 사진·문서의 권리는 각 원저작자에게 있으며, 저장소 공개가 원자료의 자유로운 재사용 허락을 뜻하지 않습니다.
